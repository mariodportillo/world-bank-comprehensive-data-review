A relationship is a starting point,

What does “average of matched years” mean?

For each country, we find years when both education spending and the selected outcome have a non-missing observation. We average each measure over that exact same set of years. Countries must meet the minimum matched-year count. Different countries can still contribute different years; use “One common year” for a shared reporting date. A one-year match is valid but provides limited historical evidence.

What is included in the comparison?

Countries and economies from the World Bank country catalog are included; regional and income aggregates are excluded. Each country has equal weight in Pearson’s correlation. It is calculated across all eligible dots, before top/bottom ranking or threshold highlighting. Fewer than three countries or a constant measure yields no correlation. Rankings use unrounded values; names break exact ties for display, so rounded values can look tied.

How are missing data and thresholds handled?

Missing observations are excluded, never replaced with zero. Zero is a valid value. Thresholds use strictly greater-than comparisons on unrounded matched averages. Adult literacy in the no-schooling view is optional context from the spending–schooling matched years; its absence does not exclude a country. That differs from the notebook’s three-way inner join. No schooling and illiteracy are different measures and are not complements.

What can these relationships tell us?

These are descriptive, contemporaneous associations. They do not estimate the effect of spending, allow for time lags, measure spending per student, or control for income, demographics and other country differences. Spending as a share of GDP is not a measure of education quality. Adult attainment reflects many past cohorts and is not a direct outcome of a single year’s budget. Missing reporting can make country samples unrepresentative.

How does the API and snapshot work?

The website opens with a saved extract from the World Bank Indicators API v2, so the initial view does not wait for the API. “Refresh from API” requests all four observation series for 1990–2025, with source IDs, pagination, timeouts, retries and cancellation. The current extract remains visible until the entire refresh succeeds. Definitions and the country catalog retain their saved snapshot date. No account, API key or BigQuery connection is used.
